OBS connection
Where do I find my OBS password?
  1. In OBS, open Tools → WebSocket Server Settings.
  2. Enable the server and keep authentication enabled.
  3. Choose Show Connect Info, then copy the server password.

Find this in OBS under Tools → WebSocket Server Settings. After a successful connection, the address and password are encrypted for your Windows account and reused automatically.
Advanced: nonstandard OBS address
